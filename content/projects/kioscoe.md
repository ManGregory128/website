- Accomplished a 64% reduction in total vehicle travel times, a 60% reduction in the number of vehicles in the network, and a 55% reduction in CO2 emissions, by developing an algorithmic approach to creating dynamic, optimal single-source bus routes based on road network demand, as measured by simulated traffic results in SUMO.
- Proposed, completed and presented a research project focused on intelligent transportation systems which enhanced my skills in software engineering, optimization, mathematical formulation, Java and XML.
- Collaborated with supervisors who helped me utilize mathematical programming and k-means clustering to form groups within a virtual road network representing Nicosia, Cyprus. Considered constraints such as demand size and bus capacity.

**Skills**: XML · Java · Mathematical Programming · Clustering · Optimization · Sumo · Algorithms
